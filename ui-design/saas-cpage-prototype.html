C 端首页 · 页面引擎双业态

同一套区块配置（section_key + payload）经「业态模板 + 术语字典 + 主题 token」渲染出两套心智。点右上角切换中医馆 / 健身房，可见：业务词、品牌名、行动色、区块组合全部随配置变化，C 端硬编码业务词 = 0。

商户在 PC 管理端配置首页区块：开关、排序、文案、封面、数据来源。保存后 C 端即时生效。左=区块库，中=实时预览，右=属性面板。这是「商户自助品牌配置」的配置面。

管理端 · 业态模板与术语字典（R2 / R3）

平台运营定义内置模板：模块清单 + 术语映射 + 默认区块。新商户选模板即得匹配页面与用语，无需代码改动（G1）。术语字典是消除硬编码业务词的核心层。

模板版本化（Q1）：升级模板不影响存量租户；存量租户继续用创建时快照，新租户用最新版。新增第三业态（美容院）只需补模板数据，不改渲染代码。

套餐能力包门控（Phase 3 · 仅门控不计费）

SaaS 套餐仅决定「可用菜单 + 可用能力」，不做计费 / 用量（已确认）。plan → menu/capability 映射在管理端隐藏无权限的菜单与模块。支付能力本身可作为某套餐专属项。

套餐导航菜单能力模块支付
基础版首页 / 预约 / 基础档案单门店 · 核心预约无
专业版+ 营销 / 数据看板 / 多门店多门店 · 内容 · 团课微信支付
旗舰版全菜单会员卡 / 分账预留 / API微信+虚拟支付
基础版无支付（R11 / Q5）：个人主体商户若需收款，须升级到专业版以上。平台不碰资金、不抽成。
