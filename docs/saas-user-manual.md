# 青囊 SAAS 管理端用户手册（多行业改造版）

> 适用版本：SAAS 多租户 + 多业态改造（中医馆 / 健身房）Phase 1.5 + Phase 1–3
> 读者对象：使用本系统的「租户管理员 / 运营人员」
> 本文档说明改造后在管理后台新增与变化的功能，不含底层部署与开发细节。

---

## 1. 产品概述

本系统采用 **SAAS 多租户架构**：同一套后端服务可同时承载多个商户（租户），如「青囊中医馆」「动能健身房」。每个租户拥有独立的数据、品牌与页面配置。

改造后管理端具备以下核心能力：

- **多租户隔离**：数据按租户隔离，管理员登录后仅操作本租户数据。
- **多业态模板**：内置「中医馆 / 健身房」两套界面与功能基调。
- **套餐门控**：通过套餐（基础版 / 专业版 / 旗舰版）控制后台可见的功能菜单与能力。
- **模板化页面**：首页、预约页、我的页的区块内容可由运营在后台可视化配置。
- **统一支付与交易**：微信支付、虚拟支付、iOS IAP 统一管理，含退款闭环。

## 3. 工作台总览（动态导航）

登录后进入工作台，注意以下变化：

- **品牌名动态显示**：左侧边栏顶部品牌名取当前租户名称（如「青囊中医馆·湖滨店」），不再是写死的固定名称。
- **导航项随套餐与业态变化**：你能看到的左侧菜单，由两部分共同决定：
  1. **业态模板**（中医馆 / 健身房）决定功能基调；
  2. **当前套餐**（基础版 / 专业版 / 旗舰版）决定开放哪些能力菜单。
- 若某个菜单「看不到」，通常是当前套餐未开通对应能力，请到「套餐管理」确认。

## 4. 页面配置（新增）

**入口**：左侧菜单 → **页面配置**

用于配置小程序端（会员端）的页面区块内容，无需改代码即可调整展示。

### 4.1 选择范围
- **租户**：默认当前租户，可切换。
- **页面**：支持 `home`（首页）、`booking`（预约）、`profile`（我的）三个页面。

### 4.2 区块管理
每个页面由多个「区块」组成，可对区块进行新增 / 编辑 / 启用：

| 字段 | 说明 |
| --- | --- |
| 区块标识 | 英文标识，如 `service_list`、`banner` |
| 标题 | 区块展示标题 |
| 排序 | 数字越小越靠前 |
| JSON 配置 | 区块具体展示内容（按模板结构填写） |
| 是否启用 | 关闭后该区块不在小程序展示 |

操作路径：点击「新增区块配置」或某行「编辑」→ 填写后保存 → 前端按配置渲染。

### 4.3 品牌设置
在同一页面可设置本租户的品牌信息：
- **名称**：展示在管理端与小程序的品牌名。
- **品牌标语**（brand_tagline）。
- **主题色**（primary，如 `#E76F3C`）：影响小程序整体配色。

## 5. 套餐管理（新增）

**入口**：左侧菜单 → **套餐管理**

用于为当前租户选择并应用套餐，从而控制后台功能范围。

### 5.1 查看套餐
页面以卡片展示所有可选套餐（如 基础版 / 专业版 / 旗舰版），每张卡片列出：
- **菜单**：该套餐开放的导航项（如 商户交易、套餐管理、内容营销 等）。
- **能力**：该套餐包含的扩展能力标签。

### 5.2 应用套餐
1. 点击目标套餐卡片选中它。
2. 点击右下角 **「应用套餐到此租户」**。
3. 保存后，左侧导航会立即按新套餐的菜单能力刷新。

> 当前生效套餐会在页面右上角标注「当前套餐：XXX」，若为默认套餐会显示「默认」标记。

### 5.3 与导航的关系
套餐决定后台「能看到哪些功能」。例如未开通「商户交易」能力的套餐，左侧就不会出现该菜单。

## 6. 商户交易（新增）

**入口**：左侧菜单 → **商户交易**

集中查看本租户的全部支付订单与退款，支持筛选与发起退款。

### 6.1 数据汇总
顶部汇总卡片展示：
- **订单数**：当前筛选条件下的订单总量。
- **有效金额**：已支付金额合计。
- **已退款**：已退款金额合计。

### 6.2 筛选
- **支付渠道**：微信支付 / 虚拟支付 / iOS IAP。
- **订单状态**：待支付 / 已支付 / 发货中 / 已发货 / 退款中 / 已退款 / 已取消。

点击「查询」应用筛选，「重置」清空条件。

### 6.3 订单列表字段
商户单号、渠道、商品类型、金额、状态等。

### 6.4 发起退款
对处于 **已支付 / 发货中 / 已发货 / 退款中** 状态的订单，可点击「退款」：
1. 填写退款原因（默认「用户申请退款」）。
2. 确认发起。
3. 系统进入退款流程，状态变更为「退款中 → 已退款」。

> 说明：退款接口已做管理员鉴权（`requireAdmin`），仅管理员可操作。

## 7. 会员端（小程序）联动说明

SAAS 改造同样影响会员端体验，管理员在后台的配置会直接反映到小程序：

- **首页 / 预约 / 我的**：区块内容由「页面配置」驱动（page-engine 共享引擎），改后台即时生效。
- **品牌与主题**：管理端设置的品牌名、主题色会同步到小程序。
- **功能可见性**：会员端展示的功能同样受租户套餐能力影响。
- **支付**：会员下单时按租户配置调用微信 / 虚拟 / iOS 支付；真实凭证就位后自动从联调占位切换为真实支付。

## 8. 常见问题（FAQ）

**Q1：登录提示「手机号或密码错误」？**
A：确认使用 `13800000000` / `admin123`；若已修改密码，使用新密码。

**Q2：登录提示「没有管理端权限」？**
A：该账号 `can_manage` 为 false，请联系超级管理员开通。

**Q3：左侧某些菜单看不到？**
A：受当前套餐能力门控，请到「套餐管理」应用包含该能力的套餐。

**Q4：页面配置改了但小程序没变？**
A：确认区块「是否启用」已打开，且已保存；小程序端需重新进入对应页面加载最新配置。

**Q5：退款一直显示「退款中」？**
A：真实支付凭证未配置时走联调逻辑；配置真实微信 / 虚拟支付凭证后由支付网关回调推进至「已退款」。

## 9. 上线前注意事项

1. **修改默认密码**：`admin123` 为弱口令，正式环境务必更换。
2. **密钥安全**：`JWT_SECRET`、支付商户号 / API Key、虚拟支付 OfferID 等应通过 Cloudflare Secret（`wrangler secret put`）注入，勿明文写入仓库。
3. **套餐与业态**：上线前确认每个租户的业态模板与套餐已正确配置，避免功能缺漏或越权。
4. **数据隔离**：多租户数据已隔离，但运营操作仍建议保留「操作日志」审计。
